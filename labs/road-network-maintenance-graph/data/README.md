# `labs/road-network-maintenance-graph/data/`

Synthetic input data for the road network maintenance lab. Nothing here is real; `gen_fixtures.py` rebuilds it.

| File | What it does |
|---|---|
| [`city_osm.json`](city_osm.json) | Synthetic city osm data. |
| [`defects.json`](defects.json) | Synthetic defects data. |
| [`demand.json`](demand.json) | Synthetic demand data. |
| [`gen_fixtures.py`](gen_fixtures.py) | Regenerates every synthetic file in this folder (deterministic seed). |
| [`incidents.json`](incidents.json) | Synthetic incidents data. |
| [`maintenance_records.json`](maintenance_records.json) | Synthetic maintenance records data. |
