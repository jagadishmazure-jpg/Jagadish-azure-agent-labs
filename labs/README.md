# `labs/`

Five self-contained labs. Each has its own README with the same 17 sections, code under `src/`, tests, an eval gate, synthetic data and infrastructure.

| File | What it does |
|---|---|
| [`disaster-signal-fusion/`](disaster-signal-fusion/README.md) | Fuses seismic, satellite, weather and displacement signals into hazard risk for a duty officer. |
| [`legal-document-compliance/`](legal-document-compliance/README.md) | Extracts clauses and tables from contracts and policies, audits them and hands them to a reviewer. |
| [`medical-eye-scan-multimodal/`](medical-eye-scan-multimodal/README.md) | Retinal-scan research triage with calibrated hypotheses and OOD denial (not a medical device). |
| [`road-network-maintenance-graph/`](road-network-maintenance-graph/README.md) | Budgeted road maintenance plan from a city graph, closure impact and priority scoring. |
| [`wind-turbine-continual-learning/`](wind-turbine-continual-learning/README.md) | SCADA diagnosis that improves only through eval-gated lessons and detector promotion. |
