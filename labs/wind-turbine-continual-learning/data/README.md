# `labs/wind-turbine-continual-learning/data/`

Synthetic input data for the wind turbine continual learning lab. Nothing here is real; `gen_fixtures.py` rebuilds it.

| File | What it does |
|---|---|
| [`episodes.json`](episodes.json) | Synthetic episodes data. |
| [`fleet.json`](fleet.json) | Synthetic fleet data. |
| [`gen_fixtures.py`](gen_fixtures.py) | Regenerates every synthetic file in this folder (deterministic seed). |
| [`learning_scenarios.json`](learning_scenarios.json) | Synthetic learning scenarios data. |
| [`maintenance_history.json`](maintenance_history.json) | Synthetic maintenance history data. |
| [`normal_train.json`](normal_train.json) | Synthetic normal train data. |
| [`stream_scenarios.json`](stream_scenarios.json) | Synthetic stream scenarios data. |
