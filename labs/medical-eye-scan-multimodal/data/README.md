# `labs/medical-eye-scan-multimodal/data/`

Synthetic input data for the medical eye scan lab. Nothing here is real; `gen_fixtures.py` rebuilds it.

| File | What it does |
|---|---|
| [`calibration.json`](calibration.json) | Synthetic calibration data. |
| [`gen_fixtures.py`](gen_fixtures.py) | Regenerates every synthetic file in this folder (deterministic seed). |
| [`library.json`](library.json) | Synthetic library data. |
| [`references.json`](references.json) | Synthetic references data. |
