# `labs/disaster-signal-fusion/data/`

Synthetic input data for the disaster signal fusion lab. Nothing here is real; `gen_fixtures.py` rebuilds it.

| File | What it does |
|---|---|
| [`gen_fixtures.py`](gen_fixtures.py) | Regenerates every synthetic file in this folder (deterministic seed). |
| [`history_archive.jsonl`](history_archive.jsonl) | Synthetic history archive data. |
| [`places.geojson`](places.geojson) | Synthetic places data. |
| [`scenarios.json`](scenarios.json) | Synthetic scenarios data. |
